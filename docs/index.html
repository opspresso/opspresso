Toast

Toast is a customizable shortcut launcher for macOS and Windows. Summon the popup with a global shortcut and run commands, open files and URLs, execute scripts, chain actions, or launch applications from your own pages of buttons. It also ships text expansion snippets, light/dark themes, and cloud sync that keeps settings and buttons in step across devices — backed by the Toast web service for sign-in and subscriptions.

Visit app.toast.sh

VibeMon

VibeMon is a real-time status monitor for AI coding assistants. A pixel art character living in your system tray shows at a glance whether the agent is thinking, working, or waiting for you, along with the active project, tool, model, and context usage. It bridges Claude Code, Codex, Kiro, and OpenClaw through their hooks, and the same status can also be rendered on an ESP32 hardware display.

Visit vibemon.io
