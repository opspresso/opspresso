Agent Delivery

delivery.agrt.dev

Console · MCP · External Secrets

Real databases and secrets for the apps agents build.

Create PostgreSQL databases, object-storage prefixes, and secrets for each repository's dev and prod environments. Agents request them over MCP, and you enter secret values in the console, never in chat. Forge runs receive dev values masked in their output. Deployed apps receive prod values through External Secrets.

  • PostgreSQL databases
  • Storage prefixes
  • Secret delivery
  • Audit trail

From request to running app

One path from an agent request to a deployed app. Each service does one part. Git, the secret store, and GitOps hold the state.

  1. 01

    Ask

    An agent in Studio takes the request with approved models, skills, and MCP tools. Studio enforces tool approvals and spending limits.

    Agent Studio · Agent Models

  2. 02

    Provision

    The agent asks Agent Delivery for a PostgreSQL database or a storage prefix for the repository. You enter secret values in the Agent Delivery console, so they never pass through chat.

    Agent Delivery

  3. 03

    Build

    Forge runs the coding CLI in an isolated sandbox with the dev values injected and masked in its output. Memory carries decisions and handoffs between sessions.

    Agent Forge · Agent Memory

  4. 04

    Ship

    Review the diff, then approve the merge and the release in Forge. GitOps deploys the app, and External Secrets delivers its prod values from the secret store.

    Agent Forge · Agent Delivery

Developer Tools

Monitor your systems, keep coding sessions running, and make everyday actions easier.

VibeMon

vibemon.io

Desktop · Web · iOS · Android · ESP32

Monitor your agents, accounts, and infrastructure.

Follow coding-agent activity and plan usage across accounts, with metrics from servers, Kubernetes clusters, DGX Spark hosts, and custom resources. View the same workspace on desktop, web, iPhone, Apple Watch, Android, or an ESP32 display, and pin it to widgets.

  • Coding agent activity
  • Plan usage limits
  • Resource metrics
  • Widgets

romty

romty.dev

macOS · Linux

Close the terminal. The shells keep running.

Keep coding agents running on an always-on machine after you close the terminal or disconnect SSH. Reconnect to the same workspace tabs, search retained output, and see which agents are working, waiting for approval, or done.

  • Persistent sessions
  • Agent resume
  • Searchable scrollback
  • Agent status

Toast

toastapp.dev

macOS · Windows

A launcher you summon with one shortcut.

A global hotkey opens your own pages of buttons. Run commands, open files and URLs, run scripts, chain actions, or launch applications. On macOS, snippets expand typed keywords in any app. Optional Cloud Sync keeps pages and snippets in step across devices.

  • Custom button pages
  • Script actions
  • Text expansion
  • Cloud sync
